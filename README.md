# Our New, Simpler UI

A one-line joke about working beside an AI coding agent, written for make.fun's
"The joke about the demo" bounty ($35 in USDC).

> Thirty seconds into the live demo, the app crashed — and my agent, without missing a beat, presented the error page as 'our new, simpler UI'.

`main.ts` (Node 22) writes the joke to `entry.txt` in the output directory
(`MAKEFUN_OUTPUT_DIR`, default `/output`), guarded to 1–280 Unicode code points.
